# 鼎烽机电商行 官网

佛山市南海区鼎烽机电商行 · 上海人民企业集团（SRM 人企）广佛总代理
纯静态站点，**不需要 Node、不需要数据库、不需要后台**，把整个文件夹传到虚拟主机 / 阿里云 OSS / 宝塔即可运行。

## 本地预览

```bash
python3 serve.py     # 然后打开 http://localhost:8811
```

## 改内容改哪个文件

| 想改什么 | 改哪 |
|---|---|
| 加 / 改 / 删水泵型号 | `data/catalog.js`（唯一数据源，普通 JSON 结构） |
| 加 / 改 / 删电机型号 | `data/motors.js` |
| 加 / 改 / 删减速机机型与速比 | `data/reducers.js` |
| 系列的用途介绍、选型要点 | `data/series-copy.js` |
| 电机 / 减速机的代理品牌 | `data/brands.js` 里的 `motors` / `reducers` 数组 |
| 首页主推的四个系列 | `index.html` 里搜 `var HOT =`，改系列 id |
| 电话、地址、店名 | `assets/js/site.js` 顶部的 `DF.TEL` / `DF.ADDR` / `DF.NAME` |
| 配色、字体、间距 | `assets/css/site.css` 顶部的 CSS 变量 |

> `data/catalog.js` 由 `build_data.py` 从 `data/raw/*.json` 生成。
> 只想小改几个型号的话，**直接改 `catalog.js` 就行**，不用跑脚本。

## 技术说明

- 无构建步骤、无框架、无外部 JS 依赖
- 外部资源只有 Google Fonts。**放国内服务器建议把字体本地化**（下载 woff2 放 `assets/fonts/`，
  改 `@font-face`），否则国内访问会慢。中文字体本来就用系统字体，不受影响
- 首页整页翻页用原生 CSS `scroll-snap`，不劫持滚轮，手机端同样生效
- 斜切三分类用 `clip-path` 多边形，悬停时切割线与楔形一起过渡；手机端自动转为横向斜切条
- 参数表全部前端渲染，2130 条数据一次加载（catalog.js 约 787KB，建议服务器开 gzip）
